# 再一次 · World Rebirth V2

一个可以离线使用的世界人口抽签小游戏。如果每个人都有一张签，你会落在哪个国家？

## 使用方式

用浏览器打开 `index.html` 即可，无需安装依赖。网页、数据、SVG 地图和分享图片生成均在本地运行。

默认进入「01 人口概率抽签」，也可切换到「02 百分位滑杆」。

## V2 功能

- **单抽与十连抽**：按候选国家人口加权。十连抽是 10 次相互独立的抽签，保留重复结果，不设置保底或改变概率。
- **国家收集册**：随机抽中的国家会解锁，并累计记录次数。手动浏览、搜索和百分位选择不会解锁国家。已解锁国家优先展示。
- **分享卡**：为当前国家生成 PNG 图片，包含人均 GDP、人口、抽中概率和无国界地图。浏览器支持时可以调用系统分享。
- **地图联动**：使用无国界陆地轮廓和国家参考定位点，不标注争议实体或边界。
- **人口分布图**：国家按人均 GDP 从低到高排列，宽度代表人口占比，纵轴使用对数刻度。
- **国家列表**：按人均 GDP 从高到低排列，可搜索、查看并直接定位。

抽签动画仅展示过程，结果在播放前已经独立抽取。中途取消时，本轮不增加记录；十连抽完成后一次性保存这 10 次结果。

## 本地进度

收集册、累计次数和最近 50 次抽签保存在当前浏览器的本地存储中，不上传到服务器，也不会跨设备或网址同步。清除网站数据可能移除进度。从离线文件切换到发布网站属于不同存储位置。

如果浏览器禁止存储、存档无法读取或写入失败，页面会明确提示当前记录仅用于本次会话，不会将保存失败显示为成功。十连抽结果面板仅保留本次打开页面期间的最近一轮。

## 数据与计算口径

- 年份：统一使用 **2024 年**。
- 来源：世界银行 World Development Indicators，源数据更新于 **2026-10-08**，下载于 **2026-10-13**。
- 范围：联合国 193 个会员国中，**186 个**拥有同年人口与名义人均 GDP 数据的国家。
- 候选人口：**7,979,040,706 人**，约覆盖同年全球人口的 **98.01%**。
- 抽中某国的概率 = 该国人口 ÷ 候选国总人口。
- 百分位在候选人口内归一化。它不是个人收入、财富或真实新生儿出生概率的排名。
- 人均 GDP 是平均经济产出，不等于个人工资、收入或生活质量。

缺少同年指标、未进入候选池的会员国为古巴、厄立特里亚、朝鲜、圣马力诺、南苏丹、叙利亚和也门。非会员地区不单列。

经济与人口数据遵循 **CC BY 4.0**；Natural Earth 地图数据属于公有领域。

- [世界银行：名义人均 GDP](https://data.worldbank.org/indicator/NY.GDP.PCAP.CD)
- [世界银行：人口](https://data.worldbank.org/indicator/SP.POP.TOTL)
- [世界银行：国家目录与参考坐标](https://api.worldbank.org/v2/country?format=json&per_page=1000)
- [联合国：会员国名单](https://www.un.org/en/about-us/member-states)
- [Natural Earth：地图数据](https://www.naturalearthdata.com/)

## 文件

- `index.html`：完整页面，已内嵌数据和地图，可单独复制使用。
- `data/dataset.json`：过滤后的候选国数据与来源说明。
- `data/countries.json`、`data/gdp.json`、`data/population.json`：世界银行原始下载快照。
- `data/natural-earth-countries.geojson`：用于生成无国界底图的公开地图源文件。
- `prepare-data.mjs`：从这些快照重新生成并嵌入页面数据。需要 Node.js，执行 `node prepare-data.mjs`；不需要安装第三方包。

## 发布到 GitHub Pages

上传后，在仓库 **Settings → Pages** 中选择 **Deploy from a branch**，指定 `main` 分支和根目录 `/`。仓库包含 `.nojekyll`，无需网站构建步骤。

分享卡在网站发布后会自动显示当前页面的网址；离线文件则注明离线版。
